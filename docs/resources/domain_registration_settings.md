# easydns_domain_registration_settings (Resource)

Manages the registrar lock and renewal action of a domain that already exists on EasyDNS. This resource adopts an existing domain; it never creates or deletes one.

```terraform
resource "easydns_domain_registration_settings" "example" {
  domain  = "example.com"
  reglock = true
  renewal = "renew"
}
```

## Destroy behavior

Destroying this resource stops Terraform managing the policy. **The remote reglock and renewal settings are left exactly as they are.** EasyDNS has no operation that clears them, and silently unlocking a domain or changing its renewal action on destroy would be a surprising registrar side effect. Terraform emits a warning saying so.

## Registrar lock support

Not every TLD supports registrar locking. When `supports_reglock` is `false`, EasyDNS ignores the requested `reglock` and the provider emits a warning; the renewal policy is still applied. The provider does not poll forever waiting for a lock the registry will never report.

## Import

```shell
terraform import easydns_domain_registration_settings.example example.com
```

## Schema

### Required

- `domain` (String) The domain whose registration policy is managed.
- `reglock` (Boolean) Registrar lock. Ignored by EasyDNS on a TLD that reports supports_reglock = false.
- `renewal` (String) Renewal action: 'remind', 'renew', or 'expire'.

### Read-Only

- `auto_renew` (Boolean) Whether automated renewal payment is configured.
- `auto_renew_card_id` (String) Card identifier used for automated renewal, when configured.
- `expiry` (String) Expiry date, or the date service is next due.
- `id` (String) The managed domain.
- `let_expire` (Boolean) Whether the domain is set to expire at the registry.
- `let_expire_failed` (Boolean) Whether EasyDNS failed to read let_expire from the registry.
- `local_registrar` (Boolean) Whether EasyDNS is the registrar of record.
- `supports_reglock` (Boolean) Whether this TLD supports registrar locking.
