# easydns_domain_nameservers (Resource)

~> **Entirely unverified.** Reading a domain's delegation failed for every domain tried against the EasyDNS sandbox, with `HTTP 400: Error encountered attempting to retrieve name servers for domain: Authentication Error`. Because the read underpins everything here, no part of this construct has been exercised against a live API. This may behave correctly in production; see the [verification status guide](../guides/verification-status).


Manages the complete delegation set of a domain. EasyDNS requires between two and ten nameservers. Delegation order carries no meaning, so `nameservers` is a set: reordering it produces no diff.

```terraform
resource "easydns_domain_nameservers" "example" {
  domain = "example.com"

  nameservers = [
    "dns1.easydns.com",
    "dns2.easydns.net",
    "dns3.easydns.org",
  ]
}
```

This resource replaces the whole set. A nameserver absent from `nameservers` is removed from the delegation on the next apply.

## Destroy behavior

Destroying this resource stops Terraform managing the delegation and **leaves the nameservers in place**. Clearing a domain's delegation would take it off the internet, so destroy never writes to EasyDNS. Terraform emits a warning saying so.

## Import

```shell
terraform import easydns_domain_nameservers.example example.com
```
