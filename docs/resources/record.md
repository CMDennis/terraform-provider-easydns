# easydns_record (Resource)

Manages a DNS record in EasyDNS. Supports A, AAAA, CNAME, MX, TXT, NS, SRV, CAA, and other record types.

Creates take a pre-write ID snapshot and select only a newly observed matching record. Updates and deletes poll by record ID until the desired state is observable. Mutations are never blindly retried after an uncertain response.

## Example Usage

### A Record

```terraform
resource "easydns_record" "web" {
  domain = "example.com"
  host   = "www"
  type   = "A"
  rdata  = "192.0.2.1"
  ttl    = 3600
}
```

### CNAME Record

```terraform
resource "easydns_record" "blog" {
  domain = "example.com"
  host   = "blog"
  type   = "CNAME"
  rdata  = "www.example.com."
  ttl    = 3600
}
```

### MX Record

```terraform
resource "easydns_record" "mail" {
  domain = "example.com"
  host   = "@"
  type   = "MX"
  rdata  = "mail.example.com."
  ttl    = 3600
  prio   = 10
}
```

### TXT Record (SPF)

```terraform
resource "easydns_record" "spf" {
  domain = "example.com"
  host   = "@"
  type   = "TXT"
  rdata  = "v=spf1 include:_spf.google.com ~all"
  ttl    = 3600
}
```

### AAAA Record (IPv6)

```terraform
resource "easydns_record" "ipv6" {
  domain = "example.com"
  host   = "www"
  type   = "AAAA"
  rdata  = "2001:db8::1"
  ttl    = 3600
}
```

### Geo-targeted asynchronous record

Use `easydns_geo_regions` to find region IDs:

```terraform
data "easydns_geo_regions" "available" {}

resource "easydns_record" "regional" {
  domain     = "example.com"
  host       = "www"
  type       = "A"
  rdata      = "192.0.2.20"
  ttl        = 600
  geozone_id = 1
  write_mode = "asynchronous"
}
```

## Schema

### Required

- `domain` (String) The domain/zone for the DNS record (e.g., 'example.com').
- `host` (String) The hostname/subdomain for the record. Use '@' for the root domain.
- `rdata` (String) The record data (IP address, hostname, text value, etc.).
- `type` (String) The DNS record type (A, AAAA, CNAME, MX, TXT, etc.).

### Optional

- `geozone_id` (Number) EasyDNS geo-region ID for this record. Zero disables geographic targeting.
- `prio` (Number) Priority for MX and SRV records (0-100).
- `ttl` (Number) Time to live in seconds. Minimum depends on your EasyDNS plan.
- `write_mode` (String) Optional record-level mutation mode override: 'synchronous' or 'asynchronous'.

### Read-Only

- `id` (String) The unique identifier of the DNS record.
- `last_mod` (String) The last modification timestamp of the record.

## Import

Import existing records using the format `domain:record_id`:

```shell
terraform import easydns_record.web "example.com:12345678"
```

To find the record ID, use the `easydns_records` data source to list all records in a domain.

Import IDs reject whitespace, extra delimiters, invalid domains, and non-numeric or non-positive record IDs. Domains are stored as lower-case IDNA ASCII without a trailing dot.

## Validation

The provider validates inputs:

- **Hostname**: Must contain only valid DNS characters (letters, digits, hyphens, underscores, dots, `@`, `*`)
- **IPv4 (A records)**: Must be a valid IPv4 address
- **IPv6 (AAAA records)**: Must be a valid IPv6 address
- **Priority**: Must be between 0 and 100
- **TTL**: Must be at least 300 seconds
- **Geo region**: Must be zero or greater

## Supported record types

`A`, `AAAA`, `AFSDB`, `ANAME`, `CAA`, `CERT`, `CNAME`, `DYN`, `MX`, `NAPTR`, `NS`, `PTR`, `SECONDARY`, `SOA`, `SPF`, `SRV`, `SSHFP`, `STEALTH`, `TLSA`, `TXT`, `URL`, and `URLHTTPS`.

Domains, hosts, and record types are canonicalized. IPv4 and IPv6 values use canonical text. DNS-name targets compare case-insensitively with one optional trailing dot, while TXT, URL, and other opaque values retain exact content.
