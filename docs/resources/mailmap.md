# easydns_mailmap (Resource)

~> **In-place updates are unverified and have failed in testing.** Against the EasyDNS sandbox, updating a mailmap answers `HTTP 406: Access to resource denied due to context restrictions` for every path form tried, while create, read and delete all succeed. A destroy followed by a create uses only the operations that work. This may behave correctly in production; see the [verification status guide](../guides/verification-status).


Creates and manages one mail-forwarding address. The API does not return a mailmap ID from create, so the provider snapshots the domain's mailmaps, sends one `PUT`, and discovers the single matching new ID through reads. Create, update, and delete are never blindly replayed after an uncertain response.

```terraform
resource "easydns_mailmap" "support" {
  domain = "example.com"
  alias  = "support"
  host   = "@"

  destinations = [
    "alice@example.net",
    "bob@example.net",
  ]
  active = true
}
```

This produces `support@example.com`. Use a relative `host` such as `lists` to produce `support@lists.example.com`. Destination order is insignificant: the provider validates, deduplicates, sorts, and compares destinations as a set.

## Updates and consistency

EasyDNS identifies updates by the old fully-qualified source address. The provider retains that address in state, sends the replacement body once, and polls the immutable `mailmap_id` until the desired alias, host, active flag, and destinations are visible. A timeout reports an error instead of guessing or issuing a second write.

## Import

Use `domain:mailmap_id`:

```shell
terraform import easydns_mailmap.support example.com:1234
```

The ID must be a positive integer. The first refresh fills in the address, destinations, active flag, and last-modified timestamp.

## Schema

### Required

- `alias` (String) Local part of the source address, without @ or the domain.
- `destinations` (Set of String) One or more destination email addresses. Order is not significant.
- `domain` (String) Domain that owns the mailmap.
- `host` (String) Relative mail host. Use @ for the domain apex, or a hostname such as lists.

### Optional

- `active` (Boolean) Whether forwarding is active. Defaults to true.

### Read-Only

- `email` (String) Fully-qualified source address derived from alias, host, and domain.
- `id` (String) Immutable numeric EasyDNS mailmap ID.
- `last_modified` (String) Timestamp last reported by EasyDNS.
