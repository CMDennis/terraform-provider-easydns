# easydns_record (Data Source)

Use this data source to retrieve one DNS record by domain, host, and type. The lookup returns an error if more than one record matches; use `easydns_records` to select a duplicate by ID.

## Example Usage

```terraform
data "easydns_record" "www" {
  domain = "example.com"
  host   = "www"
  type   = "A"
}

output "www_ip" {
  value = data.easydns_record.www.rdata
}

output "www_ttl" {
  value = data.easydns_record.www.ttl
}
```

### Required

- `domain` (String) The domain/zone to search in (e.g., 'example.com').
- `host` (String) The hostname/subdomain to find. Use '@' for the root domain.

### Read-Only

- `geozone_id` (Number) EasyDNS geo-region ID, or zero for a global record.
- `id` (String) The unique identifier of the DNS record.
- `last_mod` (String) The last modification timestamp of the record.
- `prio` (Number) Priority for MX and SRV records.
- `rdata` (String) The record data (IP address, hostname, text value, etc.).
- `ttl` (Number) Time to live in seconds.
