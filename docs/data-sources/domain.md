# easydns_domain (Data Source)

```terraform
data "easydns_domain" "example" {
  domain = "example.com"
}

output "service_due" {
  value = data.easydns_domain.example.next_due
}
```

This data source replaces the deprecated `easydns_zone` data source and returns the same fields plus `cloned_to` and `subscription_id`.

A domain that is not on the EasyDNS system returns an error rather than an empty result, matching the convention that a singleton lookup must find its object.

## Schema

### Required

- `domain` (String) The domain to look up.

### Read-Only

- `cloned_to` (String) Domain this one is cloned to, when cloning is enabled.
- `exists` (Boolean) Whether the domain exists at the registry.
- `expiry` (String) Registration expiry date, empty for a domain without registration.
- `id` (String) The EasyDNS domain identifier.
- `next_due` (String) Date the EasyDNS service is next due.
- `on_system` (Boolean) Whether the domain exists on the EasyDNS system.
- `service_id` (Number) Numeric EasyDNS service ID in use.
- `subscription_id` (Number) Subscription block ID when the domain belongs to one.
