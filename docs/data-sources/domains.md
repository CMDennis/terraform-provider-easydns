# easydns_domains (Data Source)

```terraform
data "easydns_domains" "mine" {}

output "domain_names" {
  value = [for entry in data.easydns_domains.mine.domains : entry.domain]
}
```

Omitting `user` lists the authenticated account's domains. Results are always sorted by domain name, so the collection is stable across refreshes.

EasyDNS requires a real username in this endpoint's path and rejects a placeholder, so an omitted `user` costs one extra request while the provider asks `/user` who the credentials belong to. Set `user` explicitly to avoid it.
