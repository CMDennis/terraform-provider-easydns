# easydns_geo_regions (Data Source)

Without pagination arguments, the provider follows every API page and sorts regions by numeric ID:

```terraform
data "easydns_geo_regions" "all" {}

output "region_ids" {
  value = { for region in data.easydns_geo_regions.all.regions : region.geo_code => region.id }
}
```

Set `start` or `max` to request one page:

```terraform
data "easydns_geo_regions" "first_page" {
  start = 0
  max   = 25
}
```
