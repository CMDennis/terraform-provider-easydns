# easydns_force_zone_reload (Action)

Requires Terraform 1.14 or newer. This action asks EasyDNS to regenerate a zone immediately instead of waiting for its asynchronous zone reloader.

```terraform
action "easydns_force_zone_reload" "example" {
  config {
    domain = "example.com"
  }
}
```

Invoke it deliberately:

```shell
terraform plan -invoke=action.easydns_force_zone_reload.example
terraform apply -invoke=action.easydns_force_zone_reload.example
```

The API models this side effect as `GET`, but the provider never retries it. If the response is lost or a transient server failure occurs, the result may be ambiguous. Verify the served zone before invoking it again.
