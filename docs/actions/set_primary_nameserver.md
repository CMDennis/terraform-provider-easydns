# easydns_set_primary_nameserver (Action)

Requires Terraform 1.14 or newer. This action sets the primary/master server address **and changes the domain to secondary DNS**.

```terraform
action "easydns_set_primary_nameserver" "example" {
  config {
    domain = "example.com"
    master = "192.0.2.53"
  }
}
```

Invoke it deliberately:

```shell
terraform plan -invoke=action.easydns_set_primary_nameserver.example
terraform apply -invoke=action.easydns_set_primary_nameserver.example
```

This is an imperative state transition with no reliable refresh lifecycle. The provider sends exactly one request and never retries it. If the outcome is ambiguous, inspect the domain in EasyDNS before invoking the action again.
