# EasyDNS Provider

The EasyDNS provider allows you to manage DNS records and zones hosted on [EasyDNS](https://easydns.com/) using their REST API.

## Features

- Manage DNS records, domains, registrar settings, delegation, glue, and mailmaps
- Query domain, service, subscription, pricing, user, and DNS metadata
- Invoke explicit force-reload and primary-nameserver actions on Terraform 1.14+
- Support for sandbox and production environments
- Synchronous and asynchronous record writes with read reconciliation
- Input validation for hostnames, IP addresses, and record types
- Exactly-one-write mutation handling followed by read reconciliation

## Example Usage

```terraform
terraform {
  required_providers {
    easydns = {
      source = "CMDennis/easydns"
    }
  }
}

provider "easydns" {
  environment       = "sandbox"
  record_write_mode = "synchronous"
  # Credentials via environment variables:
  # EASYDNS_API_TOKEN, EASYDNS_API_KEY
}

# Look up zone info
data "easydns_zone" "main" {
  domain = "example.com"
}

# Create an A record
resource "easydns_record" "web" {
  domain = data.easydns_zone.main.domain
  host   = "www"
  type   = "A"
  rdata  = "192.0.2.1"
  ttl    = 3600
}
```

## Authentication

The EasyDNS provider requires API credentials (token and key) which can be obtained from your EasyDNS account dashboard.

Credentials can be provided in two ways:

1. **Provider configuration** (not recommended for production):

```terraform
provider "easydns" {
  api_token = "your-token"
  api_key   = "your-key"
}
```

2. **Environment variables** (recommended):

```bash
export EASYDNS_API_TOKEN="your-token"
export EASYDNS_API_KEY="your-key"
```

## Schema

### Optional

- `api_key` (String, Sensitive) The EasyDNS API key. Can also be set via EASYDNS_API_KEY environment variable.
- `api_token` (String, Sensitive) The EasyDNS API token. Can also be set via EASYDNS_API_TOKEN environment variable.
- `api_url` (String) The EasyDNS API URL. Overrides the environment setting. Can also be set via EASYDNS_API_URL environment variable.
- `enable_domain_registration` (Boolean) Allow easydns_domain to register domains at a registry. Registration is billable and irreversible, so it defaults to false and DNS-only domains are unaffected. Can also be set via EASYDNS_ENABLE_DOMAIN_REGISTRATION.
- `environment` (String) The EasyDNS environment: 'sandbox' or 'production'. Defaults to 'sandbox'. Can also be set via EASYDNS_ENVIRONMENT environment variable. This is ignored if api_url is set.
- `record_poll_interval` (String) How often a mutation is re-read while waiting for it to become observable, as a Go duration. Defaults to 2s. Raising it spends fewer requests against the EasyDNS daily budget at the cost of settling later. Can also be set via EASYDNS_RECORD_POLL_INTERVAL.
- `record_reconcile_timeout` (String) How long a mutation is polled for before it is reported as unobservable, as a Go duration. Defaults to 2m. Can also be set via EASYDNS_RECORD_RECONCILE_TIMEOUT.
- `record_write_mode` (String) Default record mutation mode: 'synchronous' or 'asynchronous'. Defaults to 'synchronous'. Can also be set via EASYDNS_RECORD_WRITE_MODE.
- `use_async_api` (Boolean, Deprecated) Use the async API for record operations. This queues zone reloads instead of processing immediately, which may help with rate limiting. Defaults to false. Can also be set via EASYDNS_USE_ASYNC_API environment variable.
